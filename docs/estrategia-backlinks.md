## O QUE SÃO BACKLINKS?

Backlinks são links de outros sites apontando para o seu. Para o Google, cada link é um "voto de confiança". Com 2-3 links de sites relevantes, seu site ganha autoridade mais rápido.

## DICA IMPORTANTE

Não compre backlinks. Sites que vendem links são identificados pelo Google e seu site pode ser penalizado. Links naturais, de parceiros reais, são os que funcionam.
